# Wild Update Backport

All of 1.19 The Wild Update on Minecraft 1.12.2: the deep dark, ancient cities, the warden, sculk, mangrove swamps, mud, frogs, tadpoles, the allay, the recovery compass, Music Disc 5, Swift Sneak, goat horns, boats with chests and 1.19's title screen.

## Install

1. Download `WildUpdateBackport-<version>.jar` and `BackportCore-<version>.jar` from [Releases](https://github.com/ExiledRadio/WildUpdateBackport/releases).
2. Put both in your `mods` folder (Forge 1.12.2, 14.23.5.2847 or newer). Client and server both need them.
3. Optional: [Fluidlogged API](https://www.curseforge.com/minecraft/mc-mods/fluidlogged-api) 3.3.3 or newer, for waterlogged blocks.

With [Caves & Cliffs Backport](https://github.com/ExiledRadio/CavesCliffsBackport) installed, the deep dark and mangrove swamps generate where 1.19 puts them in its 1.18 worlds. Without it, this mod brings its own goats.

## Building

Needs Java 8. Put Backport Core's `-dev` jar in `deps/` (named `BackportCore-<core_version>-dev.jar`, see `gradle.properties`), then run `./gradlew build`. The jar is in `build/libs/`.
